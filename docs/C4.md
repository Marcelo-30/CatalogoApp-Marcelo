# Documentacion de arquitectura con Modelo C4

Proyecto: **CatalogoRopaMVC**

CatalogoRopaMVC es una aplicacion web individual para publicar y administrar un catalogo de ropa. La solucion usa ASP.NET Core MVC, Razor Views, Entity Framework Core, SQL Server, una API REST integrada y autenticacion por cookies para el vendedor dueno.

## C4 Nivel 1 - Contexto

**Para quien es este nivel:** personas que necesitan entender el sistema completo sin entrar en detalles tecnicos internos, como profesor, cliente o evaluador del proyecto.

**Pregunta que responde:** Que es el sistema, quien lo usa y con que sistemas externos interactua.

```mermaid
flowchart TD
    cliente["Cliente final\nConsulta prendas disponibles"]
    vendedor["Vendedor dueno\nAdministra el catalogo"]
    sistema["CatalogoRopaMVC\nAplicacion web MVC y API REST"]
    sql[("SQL Server / LocalDB\nCatalogoRopaDB")]
    imagenes["URLs externas de imagenes\nImagenes de productos"]

    cliente -->|"Consulta catalogo, filtros y detalles"| sistema
    vendedor -->|"Inicia sesion y crea, edita o elimina productos"| sistema
    sistema -->|"Lee y guarda productos, categorias, tallas, colores, imagenes y vendedor"| sql
    sistema -->|"Guarda y muestra URLs de imagen"| imagenes
    cliente -.->|"El navegador carga imagenes por URL"| imagenes
```

## C4 Nivel 3 - Componentes

**Para quien es este nivel:** desarrolladores, profesor o revisores que necesitan entender como esta organizada internamente la aplicacion principal.

**Pregunta que responde:** Que componentes internos forman la pieza principal del sistema y que responsabilidad tiene cada uno.

La pieza principal documentada es `CatalogoRopaMVC`, que contiene la interfaz MVC, la API REST, los servicios de aplicacion, los modelos de dominio y el acceso a datos. No existe una capa de repositorios separada; el acceso a datos se concentra en `ApplicationDbContext` con Entity Framework Core.

```mermaid
flowchart TD
    navegador["Navegador web"]
    apiCliente["Cliente HTTP/API"]
    sql[("SQL Server / LocalDB")]

    subgraph app["CatalogoRopaMVC - Aplicacion ASP.NET Core"]
        program["Program.cs\nDI, rutas MVC, autenticacion por cookies"]
        mvcControllers["Controladores MVC\nHomeController\nProductosController\nCategoriasController\nCuentaController"]
        apiControllers["Controladores API\nProductosApiController\nCatalogosApiController"]
        razorViews["Razor Views\nHome, Productos, Categorias, Cuenta, Shared"]
        catalogoService["ProductoCatalogoService\nConsulta catalogo y listas auxiliares"]
        authService["VendedorAuthService\nRegistro/login del vendedor dueno"]
        passwordHasher["PasswordHasher<Vendedor>\nHash y verificacion de contrasena"]
        strategies["Strategy filtros\nFiltroTextoProductoStrategy\nFiltroCategoriaProductoStrategy\nFiltroDisponibilidadProductoStrategy"]
        dtoFactory["ProductoDtoFactory\nConstruye ProductoDto"]
        viewModels["ViewModels\nLoginViewModel\nRegistroViewModel\nProductoFiltroViewModel"]

    mvcControllers -->|"CRUD de productos/categorias"| dbContext
```
